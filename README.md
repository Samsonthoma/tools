# tools

Collection of tools served at https://tools.thesouthindianschool.in

## Adding a new tool
1. Copy `tool-template.html` to `<your-tool>.html` (it already loads the shared navbar/footer via `assets/site.js`).
2. Add an entry to `assets/tools.js`. The navbar on every page and the home page grid update automatically.
3. Add the page to `sitemap.xml`.
